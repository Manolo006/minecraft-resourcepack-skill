# Add-on Resource Pack: Minecraft 1.20.2 - 1.20.4
**Resource Pack Format**: `18` (1.20.2) / `22` (1.20.3 - 1.20.4)

---

## 1. Struttura `pack.mcmeta` & Overlays Multi-Pack (1.20.2+)
In 1.20.2 è stata introdotta la possibilità di definire `overlays` in `pack.mcmeta` per supportare versioni differenti all'interno dello stesso pacchetto:
```json
{
  "pack": {
    "pack_format": 18,
    "description": "Texturepack Multi-Versione"
  },
  "overlays": {
    "entries": [
      {
        "formats": {"min_inclusive": 18, "max_inclusive": 22},
        "directory": "overlay_18_22"
      }
    ]
  }
}
```

---

## 2. Slicing e Sprite GUI (`gui/sprites/`)
- A partire dalla 1.20.2, le interfacce utente utilizzano il sistema di **GUI sprites** individuali invece di campionare enormi fogli di sprite legacy (`widgets.png`, `gui.png`).
- Gli sprite sono posizionati in `assets/minecraft/textures/gui/sprites/` e possono essere configurati con nove sezioni di slicing (9-slice) tramite file `<sprite>.png.mcmeta`:
  ```json
  {
    "gui": {
      "scaling": {
        "type": "nine_slice",
        "width": 20,
        "height": 20,
        "border": 4
      }
    }
  }
  ```

---

## 3. Font Providers (1.20.3+)
- Formattazione stringhe font e supporto a `space`, `bitmap`, `ttf`, `unihex` in `assets/<namespace>/font/`.
