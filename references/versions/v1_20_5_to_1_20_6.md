# Add-on Resource Pack: Minecraft 1.20.5 - 1.20.6
**Resource Pack Format**: `32`

---

## 1. Nuove Texture Entità: Armadillo e Wolf Armor
- **Wolf Armor**:
  - `assets/minecraft/textures/entity/wolf/wolf_armor.png`: texture base dell'armatura per lupo.
  - `assets/minecraft/textures/entity/wolf/wolf_armor_overlay.png`: strato colorabile tramite tintura (dyes).
  - `assets/minecraft/textures/item/wolf_armor.png` e relativo overlay per l'icona dell'oggetto.
- **Armadillo**:
  - `assets/minecraft/textures/entity/armadillo/armadillo.png`

---

## 2. Atlanti Particelle (`assets/<namespace>/particles/`)
La definizione delle particelle richiede file JSON dedicati nella cartella `particles/`:
```json
{
  "textures": [
    "minecraft:generic_0",
    "minecraft:generic_1",
    "minecraft:generic_2"
  ]
}
```

---

## 3. Disaccoppiamento Modelli Oggetti (Custom Model Data)
In 1.20.5, i modelli degli oggetti continuano a utilizzare `assets/<namespace>/models/item/<item>.json`, ma la gestione delle proprietà in gioco viene pilotata tramite i nuovi **Data Components** (`minecraft:custom_model_data`).
