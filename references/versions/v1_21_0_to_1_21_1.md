# Add-on Resource Pack: Minecraft 1.21.0 - 1.21.1 (Tricky Trials)
**Resource Pack Format**: `34`

---

## 1. Texture e Modelli Tricky Trials
- **Crafter (`minecraft:crafter`)**:
  - `textures/block/crafter_top.png`, `crafter_top_triggered.png`, `crafter_side.png`, `crafter_bottom.png`, `crafter_front.png`.
  - GUI: `textures/gui/container/crafter.png` e relativi sprite dei pulsanti disabilitati in `gui/sprites/container/crafter/`.
- **Trial Spawner & Vault**:
  - Texture animate con `.png.mcmeta` per le fiamme/anime interne e lo stato infausto (Ominous).
  - Modelli blocco dedicati in `models/block/trial_spawner.json` e `vault.json`.
- **Mazza (`minecraft:mace`)**:
  - Modello 3D o 2D standard in `models/item/mace.json` con visualizzazione in prima e terza persona corretta.

---

## 2. Eventi Sonori e Subtitles per Canzoni Jukebox
- Tutti i suoni personalizzati definiti nei dischi o nel registro `jukebox_song` devono avere la corrispondenza in `assets/<namespace>/sounds.json`:
```json
{
  "musica_custom": {
    "category": "record",
    "subtitle": "subtitles.item.music_disc.musica_custom",
    "sounds": [
      {"name": "mio_namespace:music/traccia_1", "stream": true}
    ]
  }
}
```
*(Nota: la musica e i dischi DEVONO sempre avere `"stream": true` per evitare di caricare l'intero file audio non compresso in memoria RAM!)*
