# Add-on Resource Pack: Minecraft 1.21.2 - 1.21.3 (Equipment Assets & Bundles)
**Resource Pack Format**: `42`

---

## 1. La Rivoluzione degli Equipment Assets (`assets/<ns>/equipment/`)
> [!IMPORTANT]
> A partire dalla 1.21.2, **la vecchia gestione hardcoded delle texture armature in `textures/models/armor/` è OBSOLETA**.
> Tutte le armature, vestiti ed equipaggiamenti (compresi cavalli, lupi ed elitre) si definiscono ora tramite file JSON in `assets/<namespace>/equipment/<id>.json`.

### Esempio di File Equipment (`assets/mio_namespace/equipment/armatura_magica.json`):
```json
{
  "layers": {
    "humanoid": [
      {
        "texture": "mio_namespace:armatura_magica"
      }
    ],
    "humanoid_leggings": [
      {
        "texture": "mio_namespace:armatura_magica"
      }
    ]
  }
}
```
Minecraft cercherà automaticamente i file `.png` nei percorsi:
- `assets/mio_namespace/textures/entity/equipment/humanoid/armatura_magica.png`
- `assets/mio_namespace/textures/entity/equipment/humanoid_leggings/armatura_magica.png`

---

## 2. Sacche Colorate (Bundles)
- 16 nuove texture e modelli per tutte le varianti di colore dei Bundle.
- Sprite di apertura/chiusura e barra di riempimento in `textures/item/bundle_*.png`.

---

## 3. Tint Sources nei Modelli
I modelli possono applicare tinte dinamiche basate sul colore dell'oggetto (`custom_model_data`, dye color, o tint del bioma) usando il blocco `tint_sources`.
