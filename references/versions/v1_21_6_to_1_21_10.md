# Add-on Resource Pack: Minecraft 1.21.6 - 1.21.10 (Strict JSON, Sprite Text & Formati Decimali)
**Resource Pack Format**: `63` (1.21.6) / `69.0` (1.21.9 - 1.21.10)

---

## 1. Strict JSON Assoluto per Resource Pack (1.21.6+)
> [!CAUTION]
> Dalla 1.21.6, qualsiasi file `.json` nel Resource Pack (`models/`, `blockstates/`, `font/`, `sounds.json`, `atlases/`) viene scartato con errore se contiene virgole finali (trailing commas) o sintassi malformata.

---

## 2. Sprite GUI nei Testi Chat e Titoli (1.21.9+)
È possibile referenziare direttamente sprite del Resourcepack nei componenti testo JSON:
```json
{"text": "Icona: ", "extra": [{"sprite": "minecraft:item/netherite_sword"}]}
```
Tutti gli sprite inclusi devono essere registrati negli atlanti del Resource Pack.

---

## 3. Notazione Decimale dei Pack Format (1.21.9+)
In `pack.mcmeta`:
```json
{
  "pack": {
    "pack_format": 69.0,
    "description": "Resource Pack 1.21.9+"
  }
}
```
